title: 1.2.0——每会话终端 + 右侧面板重构 + 权限收敛 + Harness 强化
summary: v1.2.0 - 每会话交互式终端、右侧面板重构、权限三档收敛、Harness 稳定性与安全强化
- 每会话独立终端：每个聊天会话一个持久的交互式 shell，切换会话即切换终端，支持 python/vim/htop 等交互程序
- 右侧面板重构：常驻终端 + 按需出现的上下文面板（子代理/计划/开发浏览器），不再手动切页签
- 权限模式收敛为三档：只读 / 接受编辑 / 完全放行，旧模式自动迁移，选择更简单
- 执行策略与 Agent 人格改为斜杠命令：输入 / 即可切换（/standard /code-reviewer 等），输入栏更清爽
- 计划模式升级：输入栏实时指示 + 右侧计划总结面板，进入/退出自动开合
- 移除顶栏回滚按钮与流式撤销入口（后端 checkpoint 能力保留，按轮次回滚可随时恢复）
- Harness 强化：子代理继承会话预算、自定义 Agent 有界超时、独立评审不再静默放行
- 模型回退只在服务端/网络错误触发，不再对过长/鉴权类错误做注定失败的计费重试
- 安全：自定义提示词与其它注入槽一致净化，堵住提示词框架伪造
- 文档校正：能力盘点与路线图对齐代码现状
- 冒烟/回归：Rust 1389 / clippy 0 / vitest 668
